# Factory Mobil (MVC Frontend + SQL Tasarımı)

Bu proje HTML, CSS ve JavaScript ile MVC mimarisine uygun şekilde hazırlanmış bir fabrika personel yönetim prototipidir.

## Özellikler
- Kullanıcı/Admin giriş ekranı
- İşçi kartları (ad, soyad, telefon, adres, mevki, durum)
- Bordro görünümü
- Mesai kayıtları
- İzin takip ekranı
- Admin dashboard (gelmeyen, mesai yapan, toplam kayıt vb.)
- SQL şema ve örnek kullanıcılar (`database/schema.sql`)

## Çalıştırma
Statik bir projedir. `index.html` dosyasını tarayıcıda açarak kullanabilirsiniz.

## Demo hesaplar
- Kullanıcı: `personel / 123456`
- Admin: `admin / admin123`
